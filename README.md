# Jhunlea Photography and Printing Station System

A web-based system designed to manage printing services, photography bookings, customer requests, pricing, and order tracking for Jhunlea Photography and Printing Station.

## Project Overview

The Jhunlea Photography and Printing Station System aims to make the shop's daily operations more organized and convenient. Customers can submit printing requests, upload their files, book photography sessions, view pricing, and track the status of their requests. The shop owner can manage customer orders, photography bookings, service packages, and payment records.

## Key Features

### Customer Module

* Customer registration and login
* Browse available printing services
* Submit printing requests and upload files
* View printing prices and request details
* Book photography sessions by selecting a date and time
* Choose a photoshoot theme and photography package
* Select digital-only photos or printed photos
* Track order and booking status
* View pricing and payment status

### Print Shop Owner Module

* View and manage customer requests
* Review uploaded files and printing specifications
* Manage printing orders and update order statuses
* Manage photography bookings and packages
* Set and maintain service prices
* Record payments received in person
* Monitor customer orders and booking details

### Payment Process

All payments are handled face-to-face at the shop. The owner records the payment in the system after receiving the actual payment from the customer. The system does not process online payments.

## Technology Stack

* **Frontend:** React, TypeScript, and Vite
* **Styling:** Tailwind CSS and reusable UI components
* **Package Manager:** pnpm

*Backend and database technologies may be added as development progresses.*

## Getting Started

### Prerequisites

* Node.js
* pnpm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/francineanne/Jhunlea-Photography-and-Printing-Station-System.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Jhunlea-Photography-and-Printing-Station-System
   ```

3. Install the dependencies:

   ```bash
   pnpm install
   ```

4. Start the development server:

   ```bash
   pnpm run dev
   ```

5. Open the local URL displayed in your terminal.
